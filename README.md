# Оно тебе надо

Проектная работа первого спринта курса «Фронтенд-разработка» (Яндекс Практикум): вёрстка одностраничного сайта аукциона вещей, в которые никто не верил. Макет рассчитан на экраны ноутбуков (ширина 1100px).

Репозиторий проекта: https://github.com/aMyrrh/ono-tebe-nado-ad

## Что сделано

- Семантическая разметка: `header`, `main`, `footer`, `section`, `nav`, `address`, `article`, списки `ul`/`li`.
- Шапка, секция «Об аукционе» и подвал на гридах; меню, карточки лотов, кнопка и логотип на флексбоксе.
- Обложка и карточки лотов с фоновыми изображениями и переиспользуемым оверлеем (`.overlay`).
- Шрифт Raleway подключён локально (`woff2`, `woff`).
- Имена классов в стиле БЭМ.

## Структура

- `index.html` — страница
- `fonts/` — шрифты и `fonts.css`
- `images/` — изображения и иконки
- `styles/global.css` — глобальные стили
- `styles/style.css` — стили проекта

## Запуск

Откройте `index.html` в браузере.
